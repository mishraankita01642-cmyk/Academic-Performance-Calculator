# Academic-Performance-Calculator
The Academic Performance Calculator is a Python Tkinter application that calculates SGPA and CGPA. It supports S, A, B, C, D, E, F grades and allows students to calculate their CGPA across 8 semesters. It features a simple dark-themed interface with input validation and automatic calculations.

## How to Use

### 1. Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/mishraankita01642-cmyk/Academic-Performance-Calculator.git
```

Then open the project folder:

```bash
cd Academic-Performance-Calculator
```

### 2. Make Sure Python is Installed

Check Python using:

```bash
python --version
```

Python 3.x is required.

### 3. Run the Application

Run:

```bash
python Academic-Performance-Calculator.py
```

The **Academic Performance Calculator** will open automatically.

### 4. Calculate SGPA

* Open **SGPA Calculator**.
* Enter the subject name.
* Enter the number of credits.
* Select the grade.
* Add more subjects if required.
* Click **Calculate SGPA**.

### 5. Calculate CGPA

* Open **CGPA Calculator**.
* Enter the SGPA and credits for each completed semester.
* Enter information for up to **8 semesters**.
* Click **Calculate CGPA**.

### Grade Points

| Grade | Grade Point |
| ----- | ----------: |
| S     |          10 |
| A     |           9 |
| B     |           8 |
| C     |           7 |
| D     |           6 |
| E     |           5 |
| F     |           0 |

### Requirements

* Python 3.x
* Tkinter *(usually included with Python)*
* No external Python libraries are required.
